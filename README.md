## CNN architecture: binary classifier
A project written in Python to learn more about the components of a CNN. This is a simple binary classifier, though it does contain instructions for necessary modification for multiclass classification. The data used for training and testing was the cookies vs chihuahuas dataset. The model performed reasonably well, but performance could be improved with further fine-tuning.
